## 📌 Sobre o Projeto

O **Painel Financeiro DataFlow** é um projeto de análise de dados desenvolvido no Microsoft Power BI, com foco no acompanhamento de indicadores financeiros e na transformação de dados em informações estratégicas.

O dashboard foi desenvolvido como projeto de estudo e portfólio, simulando uma solução de BI aplicada à gestão financeira empresarial.

## 🎯 Objetivo

Construir uma ferramenta analítica que permita visualizar o desempenho financeiro de uma organização, identificar as principais fontes de receita, compreender a distribuição das despesas e acompanhar indicadores de rentabilidade.

## 📈 Indicadores Financeiros

| Indicador | Descrição |
|---|---|
| Total de Receitas | Soma das receitas registradas |
| Total de Despesas | Soma das despesas registradas |
| Lucro | Diferença entre receitas e despesas |
| Margem de Lucro | Percentual de lucro em relação às receitas |

## 📊 Funcionalidades do Dashboard

**1. Visão Geral Financeira**

Apresentação dos principais KPIs financeiros para acompanhamento do desempenho do negócio.

**2. Principais Segmentos**

Visualização da participação dos componentes financeiros para identificar sua relevância nos resultados.

**3. Receitas por Componente**

Análise das fontes de receita, facilitando a identificação dos componentes com maior contribuição financeira.

**4. Despesas por Componente**

Análise da distribuição dos gastos, auxiliando na identificação dos principais centros de despesas.

**5. Resumo Financeiro**

Matriz financeira detalhada com categorias, períodos, valores e totais consolidados.

## 🛠️ Tecnologias

- Microsoft Power BI — desenvolvimento do dashboard.
- DAX — criação e cálculo de indicadores financeiros.
- Power Query — preparação e transformação dos dados, conforme implementado no projeto.
- Microsoft Excel — armazenamento e organização da base financeira utilizada.

## 🧮 Regras de Negócio

**Lucro = Total de Receitas − Total de Despesas**

**Margem de Lucro (%) = (Lucro / Total de Receitas) × 100**

As medidas utilizadas no dashboard devem respeitar as categorias financeiras e os filtros aplicados.
